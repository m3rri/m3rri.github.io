Desktop Pet

바탕화면 위를 돌아다니는 작은 친구.
일하는 동안 옆에서 놀다가, 말을 걸면 퇴근 시간도 알려 줘요.

Windows용 무료 다운로드

Windows 10 / 11 · 무료

누구랑 지낼래?

기본 캐릭터 6마리. 설정에서 언제든 바꿀 수 있고, 내가 그린 그림을 넣을 수도 있어요.

카드를 클릭하면 반응하고 말을 걸어요.

이렇게 놀아요

설치하면 바로 바탕화면에 나타나요. 캐릭터가 그려진 부분만 클릭되고, 나머지는 뒤에 있는 창으로 통과해요.

클릭

캐릭터마다 여러 동작 중 하나로 반응해요.

더블클릭

말풍선으로 말을 걸어요. 세 번에 한 번은 퇴근(또는 마감)까지 남은 시간을 알려 줘요.

드래그

원하는 곳으로 옮겨요. 다른 모니터로 옮기면 거기서 돌아다녀요.

숨기기 / 보이기

Ctrl + Alt + P 또는 트레이 아이콘 클릭. 단축키는 설정에서 바꿀 수 있어요.

설정

캐릭터를 우클릭 → 설정…, 또는 트레이 아이콘 더블클릭. 크기·속도·잠드는 시간·퇴근 시간을 바꿀 수 있어요.

종료

캐릭터 우클릭 → 종료, 또는 트레이 아이콘 우클릭 → 종료.

내 그림으로 캐릭터 만들기

설정 화면에서 새 캐릭터 폴더를 누르면 빈 폴더가 열려요. 상태 이름으로 이미지를 넣으면 끝.

idle.png      필수. 다른 이미지가 없으면 이 이미지로 대신 보여줘요
walk.gif      걸을 때
click_1.gif   클릭할 때 (click_2, click_3 … 여러 개면 무작위)
sleep.png     오래 입력이 없을 때
drag.png      끌고 다닐 때
pet.json      선택. 이름, 크기, 속도, 대사 등
  • PNG, APNG, GIF, WebP 모두 되고, 투명 배경을 권장해요.
  • 오른쪽을 바라보게 그리면 왼쪽으로 걸을 때 자동으로 뒤집혀요.
  • 모든 이미지를 같은 캔버스 크기, 같은 위치로 그리면 동작이 바뀔 때 캐릭터가 튀지 않아요.
